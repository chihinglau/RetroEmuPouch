## 3. 上架前必须补齐的 5 项缺口

### 缺口 1：没有 AAB 产物（**阻塞 Google Play**）

**背景**：Google Play 自 2021-08 起，新应用**只接受 Android App Bundle（AAB）**，不再接受 APK。
当前 `scripts/build-apk.ps1` 只产出 APK，无法直接提审 Play。

**技术待办**：

- [x] `build-apk.ps1` 增加 `-BuildAab` 开关
  - 调用 `flutter build appbundle --flavor <flavor> --dart-define CHANNEL=<flavor>`
  - 产物落 `app/build/app/outputs/bundle/<flavor>-release/app-<flavor>-release.aab`
- [x] 开启 **Play App Signing**（Play 托管应用签名密钥）
  - 生成独立 upload keystore（**不要**把 release keystore 直接作上传密钥）→ 已提供 `scripts/new-upload-key.ps1`
  - 控制台 enrollment（上传证书）仍需手动在 Play Console 完成
- [x] `ci.ps1` 增加 AAB 产物校验（存在性 + 大小 + 非 debug 签名）

**验收标准**：一条命令产出 `app-store-release.aab`，`apksigner` 校验通过，`bundletool` 可生成各 ABI APK 集。

---

### 缺口 2：软件著作权证书（国内商店硬性资质）

**背景**：华为 / 小米 / OPPO / vivo 应用提审均要求**计算机软件著作权登记证书**（软著）。

**要点**：
- **个人主体可以申请**，证书权利人为申请人本人
- 受理机构：中国版权保护中心（CPCC）
- 材料：源程序前后各 30 页（每页 50 行，去除空行与注释）、操作说明书、身份证明
- 周期：普通件约 **30–60 个工作日**；加急约 **10–30 个工作日**（以 CPCC 当期公告为准）
- 费用：普通件官方规费较低，代理/加急另计

**行动**：
- [ ] 整理源码 60 页（建议覆盖 `app/lib` 主要模块 + Kotlin 入口，避免大段空白）
- [ ] 编写操作说明书（截图 + 功能说明，10 页左右）
- [ ] CPCC 线上提交，勾选加急
- [ ] **记录软著号**，后续所有国内商店提审都要填

> ⚠️ 这是**整个国内上架路径上周期最长的一项**，必须在第 1 天就启动。

---

### 缺口 3：APP 备案（中国大陆强制）

**背景**：自 2023-09 起，未完成 APP 备案的应用不得在中国大陆分发平台上架。

**要点**：
- **个人主体可办**：需身份证、手机号、**App 包名**、**签名证书 MD5**、**隐私政策公网 URL**、App 基本信息
- 路径：先完成各应用商店开发者实名 → 在商店侧发起 App 备案（由分发平台代送审）
- 变更：包名 / 签名 / 主体 / 应用名称变更需做**变更备案**

**行动**：
- [ ] 从 release keystore 导出签名 MD5（见附录 A）
- [ ] 确认隐私政策公网 URL 可访问（缺口 4）
- [ ] 华为 / 小米各提交一次备案
- [ ] 备案通过后记录**备案号**，回填到 App 关于页

> ⚠️ 包名与签名一旦备案，**升级时不得更改**。`com.retroemupouch.app` 与 release keystore 必须长期固定。

---

### 缺口 4：隐私政策需要公网 URL

**背景**：APP 备案与 Google Play Data Safety 都要求**可公开访问**的隐私政策 URL。
当前隐私政策只有 App 内页面（`privacy_policy_page.dart`）。

**技术待办**：
- [x] 将 `privacy_policy_page.dart` 内容整理为 Markdown / HTML → 已生成 `docs/privacy.md`（公开版，覆盖全部必填模块）
- [ ] 托管到 GitHub Pages：`https://chihinglau.github.io/GamePouch/privacy`（需在仓库设置启用 Pages，源 = 仓库 `/docs` 目录）
- [x] App「关于」页新增"查看网页版隐私政策"入口（设置 → 应用 / 隐私政策页均可复制公网链接）
- [ ] 版本化（每次隐私政策更新保留历史版本）

**隐私政策必须覆盖的内容**：

| 模块 | 需声明 |
|---|---|
| 网络功能 | 联机（局域网 peer）、云同步、账号服务的用途与数据范围 |
| 数据收集 | 账号信息（如有）、设备标识、崩溃日志（如接入） |
| 本地存储 | ROM、存档、金手指、资源包**仅存本地**，不上传 |
| 第三方 SDK | 广告 / 统计类 SDK（如接入）逐条列明 |
| 儿童政策 | 不面向 13 岁以下儿童收集信息 |
| 权利行使 | 查询、更正、删除、注销账号的联系方式与流程 |
| 联系方式 | 有效的开发者联系邮箱 |

---

### 缺口 5：开源许可履约页

**背景**：MAME 为 GPL-2.0，libretro 核心多为 GPL-2.0 / LGPL / MPL-2.0。分发二进制**必须**提供对应源码获取途径。

**技术待办**：
- [ ] App 内新增「开源许可」页（设置 → 关于 → 开源许可）
  - 列出全部核心、对应许可证、项目上游地址
  - 给出**对应版本完整源码获取方式**：仓库 git tag + `scripts/` 构建脚本链接
  - 附"书面要约"文本：可邮件索取完整对应源码，有效期 3 年
- [ ] 仓库为每个发布版本打 **git tag**（源码与二进制可对应）
- [ ] 商店详情页注明："本应用基于 GPL-2.0 等开源项目构建，源码获取方式见应用内「开源许可」页"

**新增核心时的强制动作**：任何新增/升级模拟核心，必须同步更新许可证列表与仓库 tag。

## 5. 个人名义 vs 公司名义

### 5.1 逐项对比

| 维度 | 个人开发者 | 公司名义 |
|---|---|---|
| **开发者账号** | 华为 / 小米 / Google Play 均可个人实名（身份证） | 需营业执照 + 对公信息 |
| **软著** | 个人可申请，权利人为个人 | 可挂公司名下（利于后续转让/融资/入股） |
| **APP 备案** | 个人可办（身份证） | 公司办（营业执照），流程更顺，便于后续增项 |
| **应用宝 / 联运** | ❌ 基本不可行（要企业资质） | ✅ 可行（游戏类仍需版号） |
| **国内广告 SDK**（穿山甲 / 优量汇 / 百度联盟） | 多数要求企业主体 | ✅ 可接，eCPM 与填充更高 |
| **海外广告**（AdMob） | ✅ 个人可 | ✅ |
| **应用内支付 IAP**（华为 / 小米 / Play Billing） | ✅ 个人可开通，结算到个人银行卡 | 对公收款，可开票 |
| **一次性买断收款** | 个人收款码有税务/合规风险；建议第三方（爱发电 / Gumroad / FastSpring） | ✅ 正规签合同 + 开票 |
| **税务处理** | Play 海外收入属境外所得，需年度个税汇算申报；国内分成按劳务/经营所得 | 企业税制，成本可抵扣，可做亏损结转 |
| **商标注册** | ❌ 个人无法注册（需个体户/公司） | ✅ 可注册"趣玩匣"等，建立品牌护城河 |
| **法律责任** | 个人承担（版权/合规纠纷直连个人财产） | 有限责任公司隔离风险 |
| **决策效率** | 高，一人决策 | 需走流程 |
| **年度成本** | 软著费 + $25 + 备案 ≈ 数百至数千元 | 公司代账约 2000–4000 元/年 + 同上 |
| **主体变更成本** | — | 中：需重新备案 + 软著转让/重新申请 |

### 5.2 决策建议（三阶段）

**阶段一：个人名义（现在 → 月收入稳定过万前）**
- 上华为 / 小米 / Google Play / 酷安
- 变现用 IAP 买断 + AdMob（海外）
- 成本近零，快速验证市场与合规链路

**阶段二：个体户（收入稳定后，轻量过渡）**
- 注册个体户（成本低、注册快）
- 解决国内收款开票、部分广告 SDK 主体要求

**阶段三：有限公司（要接国内广告 / 上应用宝 / 融资）**
- 注册有限公司，代账约 2–4k/年
- 软著/备案/收款/商标全部迁移至公司
- 风险隔离 + 品牌资产化

> ⚠️ **主体迁移需重新备案 + 软著变更**，一次规划到位，避免反复切换。
