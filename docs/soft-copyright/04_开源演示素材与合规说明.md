## 一、为什么需要这份说明

软件本身不内置任何游戏 ROM 或 BIOS，所有运行内容由用户导入。但申报软著、上架审核或现场功能演示时，
需要实际启动游戏以证明「导入—运行—存档—导出」链路可用。若使用商业 ROM，会在截图、录屏、
审核材料中引入第三方版权内容，构成法律风险。

因此本项目单独维护一套**授权明确、允许商用与再分发**的开源/自由素材，仅用于本地演示与兼容性验证，
并保留完整授权证据。软著鉴别材料中的界面截图一律只使用本软件自有 UI，不展示任何游戏画面。

## 二、收录与隔离

| 项目 | 位置 | 是否入库 | 是否进安装包 |
|------|------|----------|--------------|
| 素材本体（ROM / 开源 BIOS） | 项目根 `freeroms/` | 否（`.gitignore` 的 `/freeroms/` 排除） | 否 |
| 授权留痕、许可证原文、清单、校验值 | `docs/freeroms/` | 是 | 否 |
| 导入复现脚本 | `scripts/import_freeroms.py` | 是 | 否 |
| 真机兼容性验证记录与原始报告 | `docs/freeroms/VALIDATION.md`、`evidence/` | 是 | 否 |

`freeroms/` 为项目根下的独立集中目录，便于后续整体隔离、迁移或删除；
本项目不使用 `.tools/freeroms`（该目录为指向另一工程的共享 Junction），避免跨工程耦合。

收录脚本只复制上游清单中 `commercial_use` 以 `commercial:yes` 开头的条目，并逐项校验
SHA256 与字节数；共收录 17 项，跳过 16 项。

## 四、许可证与署名义务

- 18 份许可证原文存放于 `docs/freeroms/licenses/`，汇总说明见 `docs/freeroms/NOTICE.md`。
- CC0-1.0：无署名义务，但仍保留来源记录。
- MIT / Zlib / BSD 类 / CC-BY-4.0：再分发或公开展示时须保留版权声明与许可文本，CC-BY-4.0 另需署名。
- GPL-2.0-or-later / GPL-3.0 / GPL-3.0-or-later：若在软件之外再分发二进制，须提供相应源代码或有效获取途径；
  本项目仅本地使用、不随产品分发，故不构成再分发，但仍保留上游地址以便核验。
- 演示时不得改名去除版权声明，不得把素材打包进安装包、软著源程序材料或文档鉴别材料。

## 六、校验与复现

1. 逐项校验：`docs/freeroms/SHA256SUMS.txt`（`sha256sum -c` 或 PowerShell `Get-FileHash`）。
2. 复现导入：`python scripts/import_freeroms.py`，脚本按 `commercial:yes` 筛选、
   校验 SHA256 与字节数、复制许可证原文、生成 `manifest.json` 与校验清单。
3. 素材本体被 `/freeroms/` 排除，克隆仓库后不会自动携带；需要演示时按上述脚本从上游重新获取。

## 七、软著材料中的使用边界

- **文档鉴别材料**：仅提交 `02_用户操作手册.md` 转出的 PDF，其中 5 张截图均为自有 UI 真机实拍，
  不含游戏画面、游戏名称或 BIOS 内容；本附表说明素材的来源与授权，但素材本体不附入鉴别材料。
- **源程序鉴别材料**：仅包含本工程自有源码（90 个文件、39394 行，取连续前 30 页与后 30 页共 60 页），
  第三方内核源码与演示素材均不在其中。
- **申请表**：软件说明统一使用「用户自行导入合法副本」口径，不出现「破解」「盗版」「免费玩付费游戏」等表述。
- **现场演示**：如需展示运行画面，优先使用 CC0-1.0 / MIT 授权的 NES、GBA 条目；
  演示录屏与截图不得写入软著鉴别材料，也不随产品分发。

## 八、建议的演示链路

1. 用系统文件选择器导入一个 CC0-1.0 或 MIT 的 NES 文件，验证 ROM 单文件导入与索引建立。
2. 在文件库搜索该条目、查看详情页的 CRC32 与文件大小，验证检索与元数据展示。
3. 点击「开始游戏」，验证内核加载、虚拟手柄、加速档与即时存读档（3 槽）。
4. 通过「✕」正常退出，验证电池存档落盘、最近游玩记录与「继续游戏」横幅。
5. 进入多选模式导出资源包，再用「导入资源包 / ZIP」反向导入，验证离线迁移链路。
6. 全程不展示商业游戏名称与画面；如需截图，仅截取设置、教程、关于等自有 UI 页面。
