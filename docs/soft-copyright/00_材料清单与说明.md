## 四、转 PDF 操作（关键，决定页数是否合规）

### 源程序鉴别材料.html
1. 用 Chrome / Edge / WPS 打开 `源程序鉴别材料.html`。
2. `Ctrl/Cmd + P` → 目标「另存为 PDF」。
3. 纸张 **A4 纵向**，边距「默认」，**取消**「页眉页脚」（避免覆盖我们的页码），缩放 100%。
4. 确认输出 **正好 60 页**（前 30 + 后 30），每页右上角有「第 X 页 / 共 60 页」。
5. 保存为 `源程序鉴别材料.pdf`。

### 02_用户操作手册.md / 用户操作手册.html
1. 推荐直接用 Edge 无头打印（截图已 base64 内嵌进 HTML，不依赖相对路径）：
   `py scripts/md_to_html_for_pdf.py` 生成 `用户操作手册.html` 后打印为 PDF（A4 纵向，取消浏览器页眉页脚）。
2. 若页数不足 60，把全部页提交；若 ≥60，取**前 30 页 + 后 30 页**提交。
3. 手册已内嵌 5 张真机截图（见上），含图页文字行数可少于 30 行（合规允许）。
