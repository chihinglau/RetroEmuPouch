## 四、转 PDF 操作（关键，决定页数是否合规）

### 源程序鉴别材料.html
1. 用 Chrome / Edge / WPS 打开 `源程序鉴别材料.html`。
2. `Ctrl/Cmd + P` → 目标「另存为 PDF」。
3. 纸张 **A4 纵向**，边距「默认」，**取消**「页眉页脚」（避免覆盖我们的页码），缩放 100%。
4. 确认输出 **正好 60 页**（前 30 + 后 30），每页右上角有「第 X 页 / 共 60 页」。
5. 保存为 `源程序鉴别材料.pdf`。

### 02_用户操作手册.md
1. 用 Typora / VS Code / WPS 打开 `02_用户操作手册.md`。
2. 打印为 PDF（A4 纵向，默认边距）。
3. 若页数不足 60，把全部页提交；若 ≥60，取**前 30 页 + 后 30 页**提交（系统中可只上传这两段，或整本上传——审查只抽看首尾）。
4. 手册里标注「图 N」处请替换为真实 App 截图（截图本身算页面内容，可少于 30 行/页）。
