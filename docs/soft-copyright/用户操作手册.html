第 1 章 软件概述

0. 软件简介

趣玩匣（RetroEmuPouch）是一款跨平台复古游戏模拟器与游戏库管理软件，支持 Android 与 HarmonyOS NEXT 系统。软件基于 libretro 模拟内核架构，在移动端提供 FC、GB、GBA、MD、32X、2600 及街机等多平台游戏的本地运行、存档管理与联机对战能力。所有游戏 ROM 与存档均保存在 App 私有目录，支持单文件备份与局域网内伙伴互导，便于用户在不同设备间迁移个人游戏进度。

0. 设计目标

本软件的设计目标包括：第一，以统一界面覆盖多种复古游戏平台，避免用户为不同主机安装多个模拟器；第二，将 ROM、BIOS、存档、金手指等文件以清晰的目录结构集中管理；第三，提供低延迟的虚拟手柄与可自定义布局，适配不同握持习惯；第四，通过局域网联机与伙伴互传，实现无云依赖的本地多人游戏与文件共享；第五，所有数据均以用户私有方式存储，强调对个人数字资产的掌控与可迁移性。

0. 主要功能一览

  1. 多核模拟：内置多种 libretro 内核，覆盖家用机与街机平台。
  2. ROM/BIOS 导入：支持系统文件管理器批量导入、伙伴互传、手动推送三种通道。
  3. 游戏库管理：按平台/类型分类、搜索、收藏与最近游玩记录。
  4. 虚拟手柄：可缩放平移的虚拟按键布局，支持招式脚本与布局导入导出。
  5. 存档系统：电池存档、即时存档（多槽位快照）、倒带回放。
  6. 局域网联机：同 Wi-Fi 双人锁步对战。
  7. 资源包导出：将 ROM、存档、金手指与 BIOS 打包为单文件离线分享。
  8. 深色主题与完全中文化界面。
  9. 账号与云同步：跨设备同步游戏库元数据与存档索引。

0. 运行环境

  • 硬件：arm64 架构智能手机或平板电脑。
  • 系统：Android 8.0 及以上，或 HarmonyOS NEXT 及以上。
  • 权限：存储访问权限（导入/导出 ROM 与存档）、局域网权限（联机与伙伴互传）。
  • 联网：联机对战与伙伴互传需处于同一局域网；账号云同步需访问互联网。

第 2 章 安装与首次配置（分平台）

1. Android 平台安装

在应用商店搜索「趣玩匣」或通过官方 APK 安装。安装完成后，系统可能提示「允许安装未知来源应用」，请按提示授予。首次打开时，系统弹出存储权限请求，点击「允许」；若使用联机或伙伴互传，还需在设置中开启「本地网络」权限。

1. HarmonyOS NEXT 平台安装

通过华为应用市场或企业分发安装。安装后首次启动，系统弹窗请求「文件管理」与「局域网」权限，请全部允许。部分版本需在「设置 → 应用 → 权限管理」中确认存储与网络权限已开启。

1. 首次配置向导

首次启动后，软件进入游戏库空白态，并提示「导入你的第一个游戏」。建议按以下顺序完成初始配置：

  1. 在「设置 → 系统文件（BIOS）」导入所需 BIOS（仅街机等平台需要）。
  2. 在「设置 → 外观」选择主题（浅色/深色/跟随系统）。
  3. 在「设置 → 手柄布局」校准虚拟按键位置与缩放。
  4. 通过任意导入通道加入至少一个游戏 ROM。

第 4 章 导入游戏与系统文件

3. 合规说明

本软件不内置、不分发任何 BIOS 或游戏 ROM。用户须从自己合法拥有的游戏副本中导入。导入的 ROM 与 BIOS 仅存储于本机 App 私有目录，不会上传至任何第三方服务器。

3. 系统文件管理器批量导入（SAF）

进入「设置 → 系统文件（BIOS）」，点击「批量导入」，在系统文件选择器中选择一个或多个文件（如街机所需的 neogeo.zip、qsound.zip），确认后软件将其放入 BIOS 目录并刷新可用性。操作时请注意：

  • 一次可选择多个文件，支持多选。
  • 导入后软件自动识别并归类到「已安装」分组。
  • 启动时若缺少某内核所需 BIOS，会弹出缺失提示并引导一次性补齐。

3. 伙伴导入

在同一 Wi-Fi 下，点击「伙伴导入」可发现局域网内其他已安装本软件的设备，选择对方共享的文件库后一键拉取所需 ROM 与 BIOS。该通道对 BIOS 文件名采用白名单限定，仅允许 neogeo.zip、qsound.zip 等已知系统文件，避免误传无关内容。操作步骤：

  1. 确认双方处于同一 Wi-Fi。
  2. 在来源设备开启「伙伴共享」。
  3. 在本机「伙伴导入」中刷新设备列表。
  4. 选择目标设备与目标文件，点击「导入」。

3. 手动推送

高级用户可通过 adb push（Android）或 hdc file send（HarmonyOS）将 ROM 直接复制到 App 私有目录的 roms 子目录下，软件在下次启动时自动扫描收录。示例命令： adb push game.zip /sdcard/Android/data/com.retroemupouch.app/files/roms/

3. 导入结果校验

导入完成后，游戏库出现对应条目；若格式不被支持，软件提示「不支持的文件格式」并跳过。

第 5 章 系统文件（BIOS）管理

4. 管理入口

「设置 → 系统文件（BIOS）」提供生命周期管理，包括批量导入、导出全部、单文件删除。

4. 分组展示

界面以三段分组展示：已安装（n）/ 缺失（n）/ 其他（n）。已安装表示内核可正常加载；缺失表示某游戏所需 BIOS 未导入；其他表示已存在但当前未关联任何内核。

4. 导出与还原

点击「导出全部」可将当前 BIOS 打成单 zip 到用户选的位置，换机时一键还原。单文件删除用于移除不再需要的 BIOS。

第 6 章 启动游戏与模拟器界面

5. 启动

在游戏库点击游戏卡片的「开始」按钮，软件加载对应 libretro 内核、挂载 ROM 与 BIOS，进入全屏模拟画面。顶部状态栏显示当前帧率与音频状态。

5. 加载过程

加载顺序为：解析 ROM → 加载内核 → 挂载 BIOS（如需要）→ 读取电池存档（如有）→ 进入主循环。任意一步失败都会在画面中央给出明确错误提示，例如「缺少 BIOS：neogeo.zip」。

5. 虚拟手柄

屏幕下半部分为虚拟手柄：左侧方向键/摇杆，右侧动作按键（A/B/X/Y 等），上方为 选择/开始/菜单 等系统键。点击对应区域即触发对应输入。手柄支持：

  • 摇杆拖拽输出连续方向。
  • 方向键提供四向/八向输入。
  • 动作键支持连发（长按触发）。

5. 运行中菜单

点击屏幕右上角菜单键可呼出运行中菜单，包含：快速存档 / 读档、倒带开关、金手指列表、画面比例与滤镜、退出到游戏库。

第 7 章 输入与手柄自定义

6. 布局缩放与平移

在「设置 → 手柄布局」可整体缩放摇杆与按键、上下左右平移以适配握持习惯。调整完成后点击「保存布局」。

6. 按键映射

支持将屏幕按键映射到内核的标准输入端口；多玩家游戏可切换玩家 1/玩家 2 输入源。

6. 招式脚本

支持为格斗游戏录制 6 槽位招式脚本（如波动拳、升龙、旋风腿），在游戏中一键触发；脚本同样可导入导出，便于多设备同步。录制方式：进入「招式脚本 → 新建」，按序输入方向键与动作键组合，保存为命名槽位。

第 8 章 模拟设置

7. 画面设置

可调节渲染分辨率倍数、画面比例（原始/全屏/整数缩放）、扫描线滤镜与色彩滤镜，以适应不同屏幕与视觉偏好。各项含义如下：

  • 渲染倍数：越高越清晰，但更耗电。
  • 整数缩放：避免非整数倍导致的像素错位。
  • 扫描线：模拟 CRT 观感。

7. 声音设置

调节主音量、声道与音频延迟；音频延迟过低可能导致爆音，过高会增加操作手感延迟，建议在中档起步微调。

7. 帧率与加速

提供正常速度、加速（快进）与慢放；可绑定快捷键。部分内核支持帧率上限解锁以适配高刷屏。

7. 金手指

在运行中菜单或游戏详情页打开金手指列表，支持启用/禁用单条代码与新建自定义代码。金手指以文本形式随存档一起备份。代码格式遵循各内核约定，通常以「地址-数值」或「GG/AR 码」表示。

第 9 章 存档系统

8. 电池存档（SRAM）

多数游戏通过电池存档（SRAM）保存进度，软件在退出游戏时自动写入以游戏 ROM 校验值为名称的 .sav 文件，下次启动自动加载。该机制保证跨设备、跨内核版本的存档身份一致。

8. 即时存档（快照）

即时存档在任意时刻捕获完整模拟状态，支持多槽位（如 1–10 号）。槽位以缩略图展示，便于区分。即时存档与电池存档相互独立，可并存。

8. 倒带

开启倒带后，软件持续缓存近期状态，长按倒带键可回退至数秒前的画面，用于规避失误。倒带会占用额外内存，可在设置中关闭。

8. 存档备份与恢复

在「设置 → 数据备份」可将全部存档导出为单文件，换机或重装时再导入恢复。备份文件包含电池存档、即时存档与金手指配置。

第 10 章 局域网联机对战

9. 概述

软件支持基于 libretro netplay 的局域网双人锁步对战，采用状态同步与输入锁步，并带有 HMAC 校验防止伪造数据包。对战要求双方运行相同内核与相同 ROM 版本。

9. 创建房间（主机）

主机在运行中菜单选择「联机 → 创建房间」，设置房间名与延迟帧数后等待；软件在本机开启服务并广播房间信息。建议延迟帧数根据网络质量设置，默认 2 帧。

9. 加入房间（客机）

客机在同一 Wi-Fi 下选择「联机 → 加入房间」，从发现列表中选择主机房间，连接成功后双方进入同步对战。掉线时自动暂停并提示。

9. 网络与延迟

联机质量取决于局域网稳定性。若频繁卡顿，可提高延迟帧数（以牺牲少量实时性换取流畅）。跨网段/公网联机不在本软件内置范围内。

9. 联机故障排查

  • 看不到房间：确认同 Wi-Fi；检查路由器是否隔离设备间通信。
  • 连接后卡顿：提高延迟帧数；关闭后台占用带宽的应用。
  • 不同步：确认双方内核版本与 ROM 一致。

第 11 章 资源包导出与导入

10. 导出

在游戏详情或批量选择模式下点击「导出资源包」，软件将所选 ROM、对应存档、金手指与所需 BIOS 打包为单个 .zip 文件，通过系统分享或文件选择器保存到用户指定位置。该包可在另一台设备离线导入，实现「开箱即玩」。

10. 导入

收到资源包后，通过「导入资源包」选择该 .zip，软件校验完整性并解包到对应目录，自动建立游戏库条目。

10. 包结构说明

资源包内部按类型分目录：roms/ 存放游戏，saves/ 存放电池与即时存档，cheats/ 存放金手指，bios/ 存放所需系统文件。

第 16 章 常见问题（FAQ）

Q1：启动游戏提示缺少 BIOS？ A：进入「设置 → 系统文件（BIOS）」批量导入对应 BIOS（如街机需 neogeo.zip），或在缺失提示中一键补齐。

Q2：联机时对方看不到我的房间？ A：确认双方处于同一 Wi-Fi；若路由器隔离了设备间通信，可改用手动地址连接，或临时关闭隔离。

Q3：即时存档读不出来？ A：即时存档与内核、ROM 版本强相关，跨内核或 ROM 版本不通用；请使用相同版本。

Q4：倒带卡顿？ A：关闭倒带或降低渲染分辨率；倒带会占用额外内存与算力。

Q5：换机后游戏库为空？ A：ROM 未随账号云同步传输，请使用「资源包导出/导入」或「伙伴导入」迁移。

Q6：导入 ROM 后游戏库不显示？ A：确认文件格式受支持；部分内核仅识别特定扩展名（如 .zip、.gba、.nes）。

Q7：声音爆音或延迟大？ A：在「声音设置」中调整音频延迟，中档起步。

Q8：虚拟按键误触？ A：在「手柄布局」中调整位置、缩小按键或开启防误触区域。

Q9：电池存档没有生效？ A：确认正常退出游戏（走菜单退出而非强制杀进程），软件在退出时写入 .sav。

Q10：资源包导入提示损坏？ A：传输过程可能损坏，请重新导出并校验大小。

Q11：手柄布局如何恢复默认？ A：在「设置 → 手柄布局」点击「恢复默认」，即可还原初始按键位置、缩放与平移。

Q12：云同步失败？ A：确认网络通畅且账号已登录；仅同步元数据，不会上传 ROM。

Q13：游戏画面比例不对？ A：在「画面设置」切换原始/全屏/整数缩放。

Q14：金手指无效？ A：确认代码格式与当前 ROM 版本匹配；部分游戏需先开启金手指再读档。

Q15：耗电过快？ A：降低渲染倍数、关闭倒带、调低帧率上限。

Q16：想要更多平台？ A：取决于内置内核；新平台随版本更新加入，详见更新日志。

Q17：数据存放在哪里？ A：全部位于 App 私有目录，其他应用无法访问，保障隐私。

Q18：如何彻底卸载？ A：通过系统应用管理卸载，私有目录一并清除；如需保留，请先备份。

Q19：是否收集隐私？ A：本软件本地优先，联机与伙伴互传限于局域网，云同步仅传元数据。

Q20：遇到无法解决的问题？ A：记录复现步骤与错误提示，通过官方渠道反馈。

第 17 章 术语表

  • ROM：只读存储器镜像，此处指游戏程序数据文件。
  • BIOS：基本输入输出系统文件，部分平台模拟所需。
  • libretro：模拟内核架构，本软件以其为前端加载多种内核。
  • 电池存档（SRAM）：由游戏自身写入的持久进度。
  • 即时存档（快照）：由模拟器捕获的完整状态。
  • 倒带：回退近期模拟状态的功能。
  • netplay：基于网络的同步对战协议。
  • 伙伴导入：同局域网设备间文件互传功能。
  • 资源包：ROM、存档、金手指与 BIOS 的打包集合。

第 18 章 技术架构简述（设计说明补充）

本软件采用分层架构：

  • 表现层：Flutter（Dart）实现跨平台 UI 与业务逻辑；HarmonyOS 端以 ArkTS + NAPI 作为原生宿主，Android 端以 Kotlin + NDK 作为原生宿主。
  • 模拟层：C/C++ 实现的 libretro 前端（gpretro），负责内核加载、帧循环、音频回调、输入映射与存档序列化。
  • 数据层：以 ROM 校验值为键的存档命名规则，保证跨设备一致性；伙伴互传基于 UDP 广播发现 + HTTP 文件服务的本地网络协议。

18. 目录结构（用户侧）

  • roms/：游戏 ROM 存放目录。
  • saves/：电池存档（.sav）与即时存档（.state）目录。
  • cheats/：金手指文本。
  • bios/：系统文件目录。
  • layouts/：手柄布局与招式脚本配置。

第 22 章 Android 与 HarmonyOS 操作差异

22. 权限入口

Android 在「设置 → 应用 → 权限」；HarmonyOS 在「设置 → 应用 → 权限管理」。两者均需授予存储与局域网权限。

22. 文件推送命令

  • Android：adb push 到 /sdcard/Android/data/com.retroemupouch.app/files/roms/。
  • HarmonyOS：hdc file send 到 /data/app/.../com.retroemupouch.app/files/roms/。

22. 后台限制

HarmonyOS 对后台进程限制更严格，长时间挂机建议保持前台或开启「允许后台运行」。

第 26 章 典型使用流程（端到端示例）

26. 场景：把一台旧设备上的 GBA 游戏迁移到新手机

  1. 在旧设备安装并打开本软件，进入「设置 → 数据备份」，导出整机备份到系统下载目录。
  2. 通过数据线或云盘将备份文件传到新手机。
  3. 在新手机安装本软件，进入「设置 → 数据备份 → 导入备份」，选择该文件。
  4. 恢复完成后，游戏库自动出现原有游戏，存档与金手指一并还原。
  5. 点击游戏「开始」即可续玩，无需重新导入 ROM。

26. 场景：两人同 Wi-Fi 联机对战

  1. 主机进入某游戏，运行中菜单选择「联机 → 创建房间」，记下房间名。
  2. 客机进入同一游戏，运行中菜单选择「联机 → 加入房间」，刷新列表后选择主机房间。
  3. 连接成功后双方画面同步，各自用手柄操作。
  4. 任一方退出联机，回到单机模式。

26. 场景：离线分享一个游戏给朋友

  1. 在详情页点击「导出资源包」，勾选本游戏、存档、金手指与所需 BIOS。
  2. 通过系统分享发送至聊天工具。
  3. 朋友收到后「导入资源包」，即可立即游玩，无需单独准备 BIOS。
