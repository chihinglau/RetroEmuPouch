# 趣玩匣（GamePouch）隐私政策

> 最后更新：2026-10-22
> 本政策为公开发布版本，与 App 内「隐私政策 / 用户协议」页内容一致。
> 正式发布前须经合规审查与个人信息保护影响评估（PIPL）。

趣玩匣（GamePouch，以下简称"本应用"）是一款**本地运行**的复古游戏模拟器工具。我们高度重视您的个人信息保护。本政策说明我们如何收集、使用、存储与保护您的信息。

## 1. 我们收集的信息

- **您主动提供的信息**：注册账号时提供的邮箱 / 用户名，以及经加盐哈希处理的登录凭据。
- **您选择同步的数据**：若开启云同步，您主动上传的**存档、游戏资源包元数据、金手指配置**仅用于跨设备同步。
- **设备与诊断信息**：用于排查崩溃与兼容性问题的设备型号、系统版本、崩溃日志摘要。**不含**精确地理位置。
- **本地内容**：您自行导入的 ROM、BIOS、存档、封面等**仅存储于您设备本地**，本应用不会读取后上传。

## 2. 我们如何使用信息

- 提供云存档、局域网联机、跨设备同步等核心功能；
- 保障账号安全、防止滥用与作弊；
- 改进应用稳定性（基于匿名化的崩溃摘要）。

## 3. 网络功能说明

本应用的网络能力**仅用于**：

- **局域网联机（peer）**：在同一 Wi-Fi 下与您的其他设备点对点通信；
- **您自己的云同步服务**：仅在您主动配置并登录后，与您指定的服务互传您自己的存档 / 元数据；
- **账号服务**：登录、会话保持。

我们**不会**通过任何网络功能上传您的 ROM、BIOS 或游戏文件。

## 4. 信息共享与转让

- 我们**不会**向任何第三方出售您的个人信息；
- 仅在法律法规要求、或应有权机关依法定程序要求时，向有关部门披露；
- 除为提供上述功能所必需的最小范围外，不与第三方共享。

## 5. 本地存储与数据安全

- ROM / BIOS / 存档 / 资源包**仅存于应用私有目录**，不上传、不下载、不共享；
- 账号凭据以加盐哈希存储；本地登录态存放于应用私有加密存储；
- 所有对外传输均采用 TLS 加密；
- 开源模拟核心（MAME / mGBA / Gambatte / FCEUmm / PicoDrive / Stella 等）均以独立原生库形式在本地运行，其代码不收集您的数据。

## 6. 第三方 SDK

当前版本**未集成**任何广告或统计分析类第三方 SDK。若后续版本接入（如海外广告 AdMob），我们将在此处逐条列明 SDK 名称、收集的数据类型与用途，并在应用内与本页面同步更新。

## 7. 未成年人保护

本应用不面向未满 14 周岁用户。如识别到未成年用户，我们将删除其账号及相关数据，并不向其提供账号服务。

## 8. 您的权利

您对个人信息的权利：

- **查询 / 更正**：在应用内查看并修改您的账号信息；
- **导出**：导出您的个人数据与存档；
- **删除 / 注销**：随时删除账号及全部关联数据（包括云端同步数据）；
- **撤回授权**：撤回此前授予的权限，撤回后我们将停止基于此权限的处理。

行使上述权利或对本政策有疑问，请通过以下方式联系我们：

- 邮箱：privacy@gamepouch.app（示例，请替换为真实可接收的邮箱）

## 9. 政策变更

本政策更新时，我们会在应用内与 GitHub Pages 同步发布新版本，并保留历史版本。若变更涉及核心处理目的或范围的重大变化，将另行提示您重新确认。

## 10. 开源声明

本应用基于 GPL-2.0 等许可证的开源项目构建（MAME 为 GPL-2.0，libretro 核心多为 GPL-2.0 / LGPL / MPL-2.0 等）。完整源码获取方式与书面要约，请见应用内「设置 → 关于 → 开源许可」。
